# 国赛问题重述

从现实情境引出明确任务，用信息组织体现理解，同时保持原题的范围、约束和交付要求。

## 范围和默认结构

默认中文论文正文，采用“问题背景 + 问题提出”两节，每问独立叙述；当前用户、教师或模板另有要求时从其要求，包括单列“已知条件”或保留既有标题。编号沿用论文。约0.5—1页是可调编辑参考，复杂题优先保全任务，实际页数需排版验证。

“帮我写第一部分”没有说明实际章节时先澄清，不预设它就是问题重述。

默认解释研究对象、现实矛盾和信息条件，再组织逐问任务；材料只支持简短背景时直接简写。已有偏好直接沿用，实质主线差异或用户要求时才给多版本。

| 请求 | 动作 |
|---|---|
| 仅审查 | 给原题与重述的差异、位置、影响及建议，保留原文件 |
| 撰写/改写 | 输出指定范围的正文，遵守已要求保留的结构与事实 |
| 修改文件 | 仅编辑明确获准内容，核对差异并保留其余章节 |

## 工作流程

1. **恢复任务结构。** 通读当前题目和附件说明，记录对象、信息、约束、每问及子任务、输出和明确依赖，保留材料位置。底稿按需展示，无需强制生成文件。
2. **分清信息身份。** 题设、直接归纳、拟用方法和未知信息分开。附件说明支持用途，实际分布和统计特征需读取数据。局部缺失时先完成确定部分；对象或主要任务不明时索取必要材料。原题与稿件冲突时据原题核对，并在正文外说明。
3. **组织背景。** 以“谁在什么情境中—什么约束使任务困难—需要解决什么”构成短段。篇幅来自解释本题，而非宏观套话。额外行业数字、政策效果和文献判断需具体来源；研究综述按明确请求扩展。
4. **保全条件，逐问重写。** 共同条件按指定结构集中交代，每问说明对象、信息、限制或新增情景和输出。保留改变可行域或口径的数字、单位、时限、文件名、多子任务和选择权。题意支持时才写前问承接，独立问题保持并列。
5. **对照验收。** 回查覆盖、数值适用范围、术语、附件角色和交付要求；检查背景中的新事实、模型选择和假设是否被误写成题设。按指定结构交付，真正影响写作的缺口集中放正文外。

重述解释研究什么：具体模型论证、假设和求解结果属于后续章节。题目要求策略时保持该要求，最优性、因果性和控制自由度以原题为准。改写句法和信息组织，保留专有名词；不声称经过查重或取得奖项。

联用问题分析时，交接各问输入输出、共同约束、新增条件、明确依赖和未决口径；只要求本节时独立完成。参考案例是作者整理的教学资料，不代表当前用户已提供那些原件。

需要 Word/MathType 公式时，读取当前环境中可用的 `mathtype-texvc`；独立安装而缺少该技能时说明转换验证缺口，普通重述仍保持任务层表达。
