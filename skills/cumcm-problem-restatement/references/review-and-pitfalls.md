# 重述的反例、修改和复核

## 常见失败与针对性修改

| 失败 | 为什么损害内容 | 修改动作 |
|---|---|---|
| 只删去题目中的形容词 | 仍沿用原题句子结构，未组织任务 | 先提取事实与任务，再重新组织段落 |
| 从“经济高速发展”铺陈数段 | 增加长度但不解释本题 | 改成对象、矛盾、任务的短背景 |
| 各问都写“依据附件建立模型” | 无法辨认每问改变了什么 | 点明对象、信息差异、约束与输出 |
| 直接写遗传算法、回归公式 | 提前进入模型分析 | 留下问题要求，把方法移到分析 |
| 把论文的目标当作题目目标 | 可能改变原问题 | 区分题目要求与拟采用的操作化指标 |
| 第二问机械“在第一问基础上” | 可能捏造数据流 | 核实继承结果、复用方法还是独立 |
| 将“仅选中对象有下限”改为“全部对象有下限” | 改变可行域 | 恢复条件适用范围 |
| 为压缩删除输出文件名 | 丢失题目交付要求 | 留下指定文件名与对应任务 |

## 实际修改示范

草稿：“社会发展让信贷越来越重要。用熵权 TOPSIS 评估所有企业，给每家公司最少 10 万元，预算都是一亿元。”

定位：背景空泛；提前定模型；把选中企业的额度下限推广到所有企业；把后问预算套到第一问。

改写方向：“银行需结合企业的信誉和交易信息识别信贷风险，并在给定资金条件下安排贷款。对确定放贷的企业，额度限定为 10—100 万元；问题一的年度信贷总额固定，问题二和问题三的总额明确为 1 亿元。”随后分别补全各问任务。

这里修正的是题意保真，不能据此宣称完整章节已写完。

## 交付前的实质复核

1. **完整性**：每问及其子任务能否与原题一一对应？输出是否覆盖风险量化与策略等并列要求？
2. **数值语义**：上下界、范围、单位和适用对象是否保持？是否存在误导性的后问条件前移？
3. **进阶价值**：背景是否解释本题矛盾，后问是否说明变化，而非添加空泛铺垫？
4. **范围**：是否混入具体算法、未确认假设、结果或未经要求的研究综述？
5. **来源**：新增事实是否有依据，样例是否被当成真实结论？
6. **篇幅**：先删重复，再压句；关键任务保留优先于建议页数。

仅审查时给出具体漏项、错误、影响与建议；用户要求改写时再交付相应修改稿，未授权不写回源文件。不用自评高分替代复核，不提供未经运行的查重率、获奖概率或排版页数。
