# 官网2020 C：信贷题的完整重述

依据 [全国大学生数学建模竞赛官网2020年赛题](https://www.mcm.edu.cn/html_cn/node/10405905647c52abfd6377c0311632b5.html) 的C题及附件整理。题面全文、附件结构和附件1全部123条企业基本信息已核对；读取范围与文件哈希见 [来源清单](official-2020-c-source.json)。以下为原创教学表达，不使用获奖论文。默认两节仅为示例结构，实际模板可另设“已知条件”。

## 题面事实卡

| 事实 | 必须保留的含义 |
|---|---|
| 中小微企业规模较小、抵押资产少 | 银行需要结合企业信息评估风险 |
| 贷款额度 10—100 万元，年利率 4%—15%，期限 1 年 | 区间适用于确定放贷的企业 |
| 附件 1：123 家有信贷记录企业 | 问题一的评价对象 |
| 附件 2：302 家无信贷记录企业 | 问题二、三的对象，信息条件发生变化 |
| 附件 3：2019 年利率与客户流失率统计关系 | 可用的信贷决策信息，不等同于已证明的因果关系 |
| 问题一：年度信贷总额固定 | 题面未在此问指定为 1 亿元 |
| 问题二、三：年度信贷总额 1 亿元 | 不可压缩成仅“预算一定” |
| 问题三：考虑突发因素的差异化影响 | 须输出调整策略，不能只评价冲击 |
| D级企业原则上不放贷 | 保留政策条件与“原则上”的语义 |
| 负数发票与作废发票不同 | 负数可对应退货退款，不能全部等同无效交易 |
| 附件1有评级、违约字段，附件2没有 | 信息条件变化是事实，不是预先求得的风险结论 |

## 可进入论文的示范正文

### 1 问题重述

#### 1.1 问题背景

中小微企业规模和抵押条件的限制，使银行在提供融资时需要借助企业信誉、交易票据及供求关系判断信贷风险。银行面临的任务是在有限信贷资源下，将企业风险识别与是否放贷、贷款额度和利率等决策联系起来，并考虑突发因素对企业经营及原有策略的影响。

题目涉及有信贷记录与无信贷记录的两类企业，二者可利用的历史信息不同；突发情景又进一步增加了策略调整的复杂性。因此，需要在明确的信息和资金约束下，分别研究常规情形的风险量化与信贷安排，以及外部冲击下的调整方案。

#### 1.2 问题提出

对确定放贷的企业，银行限定贷款额度为 10—100 万元、年利率为 4%—15%、贷款期限为 1 年；D级企业原则上不放贷。附件 1 和附件 2 分别提供 123 家有信贷记录企业及 302 家无信贷记录企业的相关数据，附件 3 提供 2019 年贷款年利率与客户流失率的统计关系。依据这些信息，需要完成以下任务。

**问题一：**针对附件 1 中的 123 家企业，综合其信誉及交易票据信息，对企业信贷风险进行量化分析。在年度信贷总额固定的条件下，给出银行面向这些企业的信贷策略，明确是否放贷及相应的额度、利率安排。

**问题二：**将研究对象扩展到附件 2 中的 302 家无信贷记录企业，在问题一研究的基础上，利用其可获得的企业和交易信息进行信贷风险量化。考虑缺少信贷记录的信息条件，在年度信贷总额为 1 亿元时，给出针对这类企业的信贷策略。

**问题三：**针对附件 2 中的企业，进一步考虑突发因素对不同产业和企业类别可能造成的不同影响，将企业原有信贷风险与冲击情景共同纳入考虑。在年度信贷总额仍为 1 亿元的条件下，给出相应的信贷调整策略。

## 为什么这样写

| 处理 | 表现出的理解 | 迁移规则 |
|---|---|---|
| 用融资、风险与有限资源组织背景 | 背景直接解释银行为什么需要模型 | 用与任务相关的矛盾替代宏观套话 |
| 单独指出两类企业的信息差异 | 问题二不只是把 123 改成 302 | 找出后问真正改变的信息条件 |
| 将共同区间集中说明 | 保全约束且避免三次重复 | 公共条件前置，特有条件逐问保留 |
| 第一问写固定总额，后两问写 1 亿元 | 没有把后问数值偷带进前问 | 逐问核对数值适用范围 |
| 写“给出策略” | 未替题目新增最优性定义 | 最优目标及证明留待分析和建模 |
| 未预判哪个行业受益或受损 | 未将示例性的行业说法泛化 | 外部冲击方向需资料支持 |

## 从普通写法升级

信息不足的压缩句：“分析两类企业风险，建立模型给出最优贷款策略。”

升级时先恢复“有/无记录”的信息差异，再恢复各问预算与冲击条件，最后恢复“风险量化 + 策略”的双重输出；不要仅增加“科学、精准、合理”等修饰词。

## 使用边界

资料核对覆盖题面、工作表结构和企业基本信息，没有完成票据清洗、特征工程或风险模型训练。已知字段可以写入任务背景，未检查的异常率、曲线性质及预测表现保持未知。具体行业冲击需依据，方法是否可迁移由问题分析论证，重述只保留任务及条件。
