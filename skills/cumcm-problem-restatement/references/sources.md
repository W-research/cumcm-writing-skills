# 材料来源与适用范围

本库由作者 W 整理。除官方来源O-C2020外，U编号是作者历史资料的索引，不表示当前用户提供过这些材料；原件未随包收录。它们支持教学写法辨析，不认证原论文奖项或完整题意。普通写作无需向当前用户索取这些历史原件；核对当前任务使用当前题目与材料。
