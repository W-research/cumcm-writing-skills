# 标题与关键词

## 从正文提炼标题

先提取三个要素：研究对象、主要任务、支撑主要结论的模型。方法确实具有辨识度时优先考虑方法型标题；多问方法差异很大、没有共同主模型时，问题型标题更自然。以下只是句式，不是必须逐字采用的模板。

| 类型 | 句式 | 适用情形 |
| --- | --- | --- |
| 方法型 | 基于〔主要模型/方法〕的〔对象〕〔预测/控制/优化任务〕 | 核心方法贯穿主要任务，能解释论文特点 |
| 机理型 | 基于〔物理机制〕的〔对象〕〔建模/设计任务〕 | 机理推导是主线，数值算法承担求解 |
| 问题型 | 〔研究对象〕的〔核心任务〕 | 任务本身明确，方法多样或不宜压成单一标签 |

教学中的“基于数值模拟的高压油管压力控制模型”体现方法与对象任务的结合；“校园供水系统智能管理”体现直接概括研究任务的方式。后者只有在实际工作支持该范围时才适合沿用；“智能”不是自动增色的修饰词。

### 比较候选标题的顺序

1. 准确：标题中的对象、方法、任务能在正文找到支持。
2. 覆盖：能概括主要问题，不把最复杂的一问误当整篇。
3. 聚焦：保留核心数学方法，去除次要预处理、软件和实现语言。
4. 可读：中文语序自然，避免多层“基于……的……与……的研究与构建”。

无需人为设统一字数硬限；有模板限制依模板，否则以信息准确和实际版面为准。方法很长时可用正文认可的规范类别概括，不得改成另一个模型。

### 有条件的改写示例

- 原标题：“基于 Python、差分、积分和遍历算法的高压油管研究”。若正文以压力动力学建模与控制为主，可改为“基于压力动力学模型的高压油管控制策略研究”；若数值模拟确实贯穿全文，可考虑教学中的数值模拟标题。
- 原标题：“基于聚类、决策树、非线性规划和爬虫的中小微企业研究”。若主要交付是风险评估和贷款决策，可提炼为“中小微企业信贷风险评估与贷款策略优化”；正文确有清晰主方法时再考虑方法型标题。
- 原标题：“最精准的炉温曲线智能优化模型”。删除未经证实的最高级；仅当正文确用热传导机理时，才可改为“基于热传导模型的炉温曲线预测与优化”。

不要因为示例措辞好看就替用户换研究路线。

## 选择关键词

从正文实际出现的术语中选择，优先级通常为：核心对象/任务 → 主模型 → 关键求解或验证方法。建议 4–6 个，但允许依据篇幅、内容和明确要求调整。

| 候选问题 | 处理 |
| --- | --- |
| “数学建模；模型；分析；优化” | 过于宽泛，换成确实使用的对象词和具体模型名 |
| “Python；MATLAB；SPSS” | 通常是实现工具，不能代替数学方法 |
| “优化模型；最优化模型；规划模型” | 语义高度重叠，按正文选一个有区分度的规范名称 |
| “热传导方程；牛顿冷却定律；差分法” | 各自承担不同作用且正文确有使用时可以并列 |
| 中文名与英文缩写重复占两项 | 合为一个术语，如“极端梯度提升（XGBoost）”，仅在名称对应正确时使用 |

例如，压力控制论文若确实使用相应方法，可选“高压油管；压力控制；常微分方程；有限差分法；数值优化”。若正文只称一般差分法，不擅自升级为更具体算法。关键词用“关键词：”引出，分隔符服从模板，无指定时中文分号即可。
