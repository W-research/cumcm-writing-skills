# 国赛论文首页

将已有研究整理为可独立阅读的标题、摘要和关键词，使读者看清任务、建模方法、主要结果及适用条件。语言、篇幅、格式与保留内容服从当前请求和目标模板。

## 先确定交付范围

| 请求 | 交付 |
|---|---|
| 仅审查、诊断 | 原文位置、问题、影响和建议；保持源文件不变 |
| 新写、润色、改写 | 指定范围的文案；只有另有明确文件修改请求时才写回 |
| 修改文件 | 编辑获准内容，核对差异并保留其余部分 |
| 只加粗 | 仅添加强调格式，文字、数字、段落和结尾保持原样 |
| 只要标题或关键词 | 直接处理对应部分，无需扩写整页 |

材料不完整时，完成可确认部分，集中说明真正影响成稿的缺口。没有研究对象、方法或结果时索取必要材料。局部润色可保留原文数字并说明未核验；终稿需对照题目、正文和结果。分别说明“文案已整理”“内容已核对”“版式已验证”。

## 按需读取

- 新写或实质重写摘要：读 [摘要写作与精简](references/abstract-writing.md)，其中统一维护题型写法、加粗细则和压缩示例。
- 标题或关键词：读 [标题与关键词](references/title-keywords.md)。
- 主线、详略或结尾存在实质取舍：读 [方向选择](references/decision-points.md)。要求直接出稿时给推荐稿，已明确的偏好直接沿用。
- 历史教学数字或来源核对：读 [教学材料与边界](references/teaching-examples.md)。这些是作者整理的材料，与当前会话输入无关。
- 完整输入到首页的对照：读 [自包含算例](references/worked-example.md)。
- 官方数据题的摘要证据准备：读 [2020 C事实与完成状态](references/official-credit-evidence.md)。
- 指定届次的提交合规核对：读 [竞赛合规](references/competition-compliance.md)。

## 工作流程

### 1. 提取任务与结果

通读当前提供的题目和论文材料，按每问整理：

小问/子任务｜应交付内容｜模型及作用｜关键结果、单位和条件｜证据位置或缺口

该表内部使用，复杂诊断时再展示。优先解决漏子任务、只有方法没有答案、模型与任务脱节，其次处理数字堆积、重复和语言。按现有资料定位即可，无需创建特定名称的结果台账。

### 2. 确定主线与标题

标题覆盖主要任务，突出真正支撑研究的模型或问题。方法型标题可以使用“基于……的……”，多问方法差异大时采用问题型标题。通常提炼一个核心方法，必要时保留两个配合的方法；软件、清洗步骤和边缘算法留在正文。

“最优、精准、创新”等承诺与正文证据相称。只要一个标题就给推荐项；存在实质取舍才给不同候选。摘要完成后回看标题，检查是否只覆盖第一问或夸大次要方法。

### 3. 组织摘要

开头简要交代对象与实际工作；背景只保留理解本题所需部分。主体按问题或真实任务结构展开，使问题、方法和答案对应：

- 优化题说明目标、决策变量和关键约束，报告方案、目标值或边界。
- 机理题说明主要机制及模型作用，报告所求物理量与条件。
- 预测和评价题说明输入、目标与模型作用，报告预测、排序、分组或诊断。
- 策略题给行动规则、触发条件或关键安排，算法名称不能代替策略。

每个主要任务均有答案，子任务完整保留。数值优先级为直接答案、方案条件、阈值/约束边界、基线比较、已有验证；数量由信息价值决定。长方案用关键结果加准确的位置索引或题设指定文件去向概括，并核对该位置/文件确实存在。

结尾有综合发现、适用范围或经验证的特点时保留；用户要求保留就写出实质内容。没有新增信息时可合并或省略。不能以“精简”为由静默删去明确要求保留的结果和结尾。

把适用范围写进结果句，按[事实范围与正文外说明](references/abstract-writing.md#事实范围与正文外说明)区分必答结果和工作状态。

### 4. 选择强调与关键词

可排版摘要默认适量加粗主模型、关键机制和主要答案，细则在 [摘要写作参考](references/abstract-writing.md) 统一维护。纯文本、原格式或模板另有要求时从其规定。完整词组连同必要指标、单位一起强调；只加粗任务保持原字句。

关键词取正文实际使用的对象/任务、核心模型及必要方法，通常建议4–6个，数量服从模板。选有区分度的术语并合并近义重复，软件名一般不代替数学方法。名称在标题、摘要、关键词和正文中一致。

### 5. 核对证据与篇幅

把以下事项集中检查一次，而不是在每句正文后加防御性说明：

1. 数字的版本、对象、情景、时间区间、单位、精度和来源一致。冲突或疑似OCR错误先标出，确认后处理。
2. 比较保留基线和指标口径，分别写清百分点与相对百分比。模拟、实测、相关和因果各用与证据相符的表述。
3. 全局最优需要相应保证；有限搜索可写搜索最佳或较优方案。“显著、稳健”等主张使用已完成的检验依据。
4. 教学示例只帮助组织表达。当前首页的对象、方法和数值均来自当前研究；来源编号与奖项标签不能证明新论文结果。
5. 首页通常容纳标题、摘要和关键词。约1000字是编辑经验而非统一要求；实际页数需按目标格式渲染核对。超页先压缩背景、推导、重复和次要结果，保留必答内容及规定字号。

要求比赛提交合规时，核对指定届次官方规范和 [竞赛合规说明](references/competition-compliance.md)。声明按规定位置安排，不自动塞入摘要页。奖项、查重率、页数和原生公式转换效果都只能按实际验证范围报告。

## 输出

整套首页按标题、摘要、关键词顺序交付，复制区域仅放论文文案。审查意见、取舍理由、待补证据和排版状态放文案外，保持授权范围与事实强度。

确有必要附工作说明时，在关键词后使用单独一行 `---`，随后以“正文外说明”为标题；也可直接用该标题明确分区。没有实质缺口时可省略说明区，切勿为了固定格式制造缺口。

需要 Word/MathType 公式时，按当前环境中可用的 `mathtype-texvc` 规则输出；独立安装而缺少该技能时说明专用转换验证缺口，普通文字与原生LaTeX任务照常完成。
