# 国赛模型假设

把现实问题简化到能够建模，同时保留题目要研究的机制。每条假设说明：对什么对象、在什么范围作何近似、支撑模型哪一步、依据是什么。

## 工作状态与交付权限

方案稿从题目和已选路线提出候选前提；论文回写从实际公式、代码、目标约束和数据处理追溯前提。局部缺材料时完成确定部分；关键题意歧义用条件分支或必要澄清处理，不用假设悄悄代替题意。

仅审查时给位置、问题、影响和建议，保持原文件不变。改写时提供指定范围的替换稿；明确要求修改文件才写回并检查差异。建议假设变化若影响计算或结论，先说明影响，模型变更遵守相应授权。

## 工作流程

### 1. 判断条件身份

分清题设、严格推论、新增简化、模型/统计前提、指标定义与待求结论。题设理想化可注明来源承接，普通参数和任务无需重抄。指标设计在模型中论证，数值步长和精度在求解/检验中处理。

随机问题还要区分信息结构、偏好、单条实现路径与事前策略的可行性标准。按原题采用硬约束、失败计分或概率要求，避免额外强化为全情景成功或擅自放宽约束。

### 2. 筛选真正需要的假设

内部记录“陈述—范围—模型落点—依据与状态—失效影响—验证或放宽办法”，保留材料位置。用反事实判断必要性：去掉它后哪个方程、参数解释、可行域或结果会改变？没有具体落点的条目删除、合并或移到相应章节。

共同条件只写一次，局部假设标出问题、对象与时段。后问新增冲击、未知信息或几何条件时，重新确认继承范围。

### 3. 评价强度与证据

依据可来自题设、机理/量级、当前数据、适用的外部资料，或明确的暂定选择。计算便利是动机，合理性要联系任务尺度和目标输出。

集中守住这些边界：保留研究核心因素；低概率事件同时考虑影响；缺失和未测到不当作零；模型前提随用途选择；待求最优性不能预设；未拒绝不等于证明。正文使用与证据相称的条件化陈述，关键弱假设配局部诊断或结构对照。已取消核心任务的假设需在当前方案中修正，而非留到未来改进。

### 4. 写成简洁章节

沿用现有标题和编号。默认必要的有序条目，每条含准确条件及简短依据/作用，核心短语可加粗，条数由需要决定。共同条件在前、局部条件在后，确有层次才分小节。

正文保留理解前提所需依据，详细检查、材料缺口和争议放正文外。已有证据直接陈述其范围，避免反复加“待核实”。有数据且要求局部验证时，记录数据、方法和真实结果，保持当前任务范围。

### 5. 对照回写与输出

逐条核对题意、模型落点、量词/单位、跨问范围与证据状态。检查文字声称忽略/考虑的因素是否与方程、代码相符，结论是否越界。只要本节时只交本节，独立缺口简短说明。

参考资料是作者整理的教学材料，不是当前用户的历史输入。它们帮助判断，不能为当前论文提供未经取得的实验结果、奖项或假设证明。

需要 Word/MathType 公式时，读取当前环境中可用的 `mathtype-texvc`；独立安装而缺少该技能时说明转换验证缺口，格式转换不改变假设的证据状态。
