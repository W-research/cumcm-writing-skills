# 写作与复核

## 正文形态

默认交付“模型假设”标题和必要的编号条目，沿用全文编号。推荐每条包含完整条件和一项具体解释；不是每条都必须机械分成“假设、依据、作用、验证”四段。

> **在单次稳定运行期间，将炉内环境温度视为空间位置的函数。** 该近似将外部温度场作为给定边界条件，同时保留元件随时间发生的温度变化。

该句要以稳定工况为采用条件，不是无数据时已经证实的结论。相比“假设炉温稳定，便于建模”，它说清了稳定的对象、范围和简化位置。

存在实质缺口时，正文外用简短说明列出；没有缺口就不另造“待核对事项”。用户要求审查时可使用表格，用户只要正文时不附整张审计台账。

## 完整迁移示例：板凳龙的几何运动方案稿

### 输入与采用边界

来源：作者整理的 2024 年国赛 A 题“板凳龙”及已形成的分析方案。涉及板凳连接运动、首次碰撞、调头与把手限速；模型拟采用固定孔心距、全板矩形碰撞表示和路径几何运动学。此处没有计算结果或验证数据。

以下为该方案下的原创示范，不是获奖论文摘抄；不能在其他路线中整组照用。题设给定的板长、板宽、孔位和路径参数应在相关章节保留，这里不重复罗列全部数字。

### 可用正文

## 模型假设

1. **将各板凳视为保持形状与尺寸不变的刚性构件，忽略运动过程中的弹性形变。** 相邻连接孔中心的距离由板凳尺寸确定，据此描述板凳之间的几何约束；该近似的适用范围限于形变不足以明显改变运动构型的情形。

2. **把手连接按孔中心处的理想转动连接处理，基准几何模型不单独描述连接间隙。** 该近似允许相邻板凳绕共享连接位置转动，并保持连接位置一致；它不要求不同把手具有相同速度。

3. **碰撞分析以板凳完整平面轮廓建立几何判定，保留板宽与孔外端部。** 题设连接方式允许的局部搭接与其他部位接触应分别处理；不将合法连接处的投影重叠直接判为碰撞，也不因此免除其余部位的检查。

4. **在碰撞发生前及经可行性检查的运动区间内，采用题设路径上的几何运动学描述。** 不额外引入题目未要求的受力和驱动响应方程；碰撞后的动力学不属于该模型的描述范围，各把手速度仍由各自的运动关系确定。

### 正文外说明示例

上述为几何方案的假设稿。当前未提供形变、连接间隙和高度差的测量依据，平面判定与合法搭接范围需要结合原题图示明确；临界碰撞附近应特别检查这些近似的影响。路径能被按指定方式跟随不构成路径可行性的证明。

### 为什么保留这四项

| 项目 | 模型落点 | 不能从它推出什么 |
|---|---|---|
| 刚性构件 | 固定几何距离 | 曲线路径上的固定弧长间隔、各把手等速 |
| 理想连接 | 共享孔中心、相对转动 | 允许所有相邻板凳任意重叠 |
| 平面轮廓 | 碰撞近似及端部处理 | 仅靠中心线距离足以判断实际接触 |
| 几何运动范围 | 沿路径求位置与速度 | 永不碰撞、驱动力一定足够、调头方案必然可行 |

示例没有将“求得最小螺距”“没有碰撞”“全程所有把手等速”列作前提，也没有添加图或完整求解。是否需要独立的参数/统计假设由实际路线决定。

## 审查时按影响给出具体修订

| 症状 | 为什么影响模型 | 修改方向 |
|---|---|---|
| “所有误差均无影响” | 混淆理想化、观测误差与数值误差 | 定位误差来源，限定基准近似，安排针对性检查 |
| “数据完整可靠” | 可能掩盖缺失、偏差与覆盖不足 | 分开核对测量质量与样本覆盖，不把未知当零 |
| “系统完全稳定” | 稳定对象、时间尺度和性质不明 | 写明拓扑、温度场、参数或概率中的具体哪一项 |
| “只考虑 A，其他都无关” | 可观测不代表唯一原因 | 改为当前模型显式纳入 A，并说明未纳入项的依据与边界 |
| “假设所得解为全局最优” | 把应证明的结果当条件 | 删除，移到求解与验证中依据证据讨论 |
| “无突发事件”贯穿全部问题 | 与冲击/应急子任务矛盾 | 限于基准情景，后问恢复相应因素 |
| “模型越复杂越创新” | 额外因素可能无法识别或没有贡献 | 用数据支持、结果影响和任务覆盖判断价值 |

审查结果可以写成“原条目 → 实质问题 → 影响 → 建议”，无需给每条假设打分。用户要求建议措辞时才附局部“建议正文”；要求改写时再修订授权范围内的措辞和重复，只有明确要求修改文件时才写回。涉及模型改变的，先说明它具体改变哪项计算或结论，不以审查授权代替模型变更授权。

## 联用与回写

问题重述确认任务，问题分析解释路线，模型假设限定成立条件。不要把三节写成重复的模型计划。

回写时从实际公式、代码和输出查前提。例如代码使用正态噪声模拟而正文只写“存在随机误差”，应补充真实分布设定及依据状态；正文写“考虑辐射”而模型没有对应项或等效处理，应指出不一致，不能凭空宣布已经考虑。

未进行模型验证的回写仍应保持证据边界。若用户只要求润色，正文外指出关键不一致，保留用户指定结果；不要替换整套模型或重新计算全文。
