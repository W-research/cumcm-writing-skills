# 筛选与适用范围

## 六类来源，六种处理

作者整理的材料中的六类常见情况适合作为候选来源，不是每篇论文都应凑齐的目录。

| 来源 | 可以保留的内容 | 采用前的判断 |
|---|---|---|
| 题目明确给出的假设 | 如某问出发前知道完整天气序列 | 注明“按题设”，只适用于题目指定问题，勿推广到随机天气问 |
| 排除非常态事件 | 限定在正常运行工况的交通或生产基准模型 | 事故是否恰是任务核心？概率小是否仍会改变损失或可行性？ |
| 舍弃次要因素 | 小尺度形变、局部边缘效应等对当前输出的近似 | 相对哪个主效应或误差容限较小？有何依据？ |
| 模型成立条件 | 明确状态下的 Markov 性、估计或推断所需条件 | 是实际方法的前提，还是看见模型名称后补的套话？ |
| 参数/函数/分布形式 | 局部常参数、候选寿命分布、增长规律 | 对象、单位、时段、参数来源、备选与诊断是否明确？ |
| 与题目紧密结合的结构简化 | 稳定炉温、刚性连接、分层计量的时间对齐 | 能否指出它简化了哪个关系，而没有取消题目难点？ |

## 条件身份不要混淆

- “龙头速度按题设为 1 m/s”：题设条件，不是从数据发现的规律。
- “给定板长及孔端距推出孔心距”：几何推论，不必称为假设。
- “板凳在研究过程中视为刚体”：若原题未直接规定，是新增结构理想化，支撑固定孔心距关系。
- “各把手速度均相同”：通常既非题设也非刚性连接的推论，可能直接毁掉速度研究任务。
- “用最大个体风险定义组合指标”：首先是指标设计，要解释为何符合决策目标，不是自然规律。
- “算法得到全局最优”：待证明或待验证的结论，不能预置为模型假设。

章节中可以出现必要的题设理想化，但不要把题设数值、变量定义和建模者假设混成一长串。

## 必要性：看模型落点

用一句反事实检查候选项：“若不作此假设，模型需要增加/改变什么？”

合格示例：不采用恒定炉温场，就需引入炉温随时间变化；不采用刚性板凳，就需增设形变自由度；不采用给定状态的 Markov 近似，就需加入历史特征或改用带记忆模型。

不合格示例：“无战争”“全体人员遵守法律”“不存在未知因素”与当前数据、方程和输出没有具体联系。即使现实上有意义，也不应成为通用填充项。

如果一个事实已由数据证实或题设规定，不必为了格式再写成不确定假设；如果只是没有数据，不能因此设为零。

## 范围：共同、局部与情景切换

| 情景 | 正确继承方式 | 常见越界 |
|---|---|---|
| 已知天气 → 随机天气 | 保留资源消耗规则，替换信息结构 | 后问仍允许使用未来真实天气 |
| 日常信贷 → 突发冲击 | 保留贷款约束，调整受冲击参数或情景 | 全文假设没有任何突发事件 |
| 有标签企业 → 无标签企业 | 共享特征口径；迁移关系须有依据 | 将信誉标签缺失解释成零风险 |
| 常规运动 → 首次碰撞 → 调头 | 继承尺寸，重新检查接触与路径范围 | 为推导速度而假设永不碰撞 |
| 稳态分区 → 过渡区 | 分区恒定可保留，过渡区单独处理 | 把整个炉腔都当成同一个温度 |

题目没有明确的口径（如可否改变圆弧半径比）应作为解释选择说明；不能只写“假设允许”而让读者误以为原题授权。

## 假设过强时的处理顺序

先判断它是否取消核心任务。若是，修改模型或限定当前仅为基准方案，不能用后文评价补救。

若核心任务仍成立，可依次考虑缩小有效时段/对象、保留一个有界扰动、分组或分段参数、增加必要状态、对多种结构做情景比较。选择适合任务且现有材料支持的最小改动，不默认上复杂模型。

主结果高度依赖而无法核验的假设要如实说明。增加因素不自动构成创新，也不自动提高准确性；要看辨识能力、数据支持及新增因素对目标结果的贡献。
