# 模型前提辨析

本文件用于避免从模型名称机械生成假设。下列前提都是候选，只有实际采用的方法及其用途需要时才进入论文。

## 回归：区分拟合、参数解释与推断

普通最小二乘的平方损失求解不以误差正态为计算前提。若要作经典线性模型下的无偏性、方差或精确有限样本推断，需要逐一说明相应条件；不能把这些用途混在一句“回归要求独立正态”里。Gauss–Markov 模型可不施加正态性；经典正态线性模型中的精确 t/F 推断有额外条件。[MIT：计量经济学讲义](https://ocw.mit.edu/courses/14-382-econometrics-spring-2017/29d3e55c546c9927eff0035735b35aa9_MIT14_382S17_14381notes.pdf)、[MIT：有限样本推断讲义](https://ocw.mit.edu/courses/14-385-nonlinear-econometric-analysis-fall-2007/d6bfdd254deebcaeae7a3470eac8953c_lecture06.pdf)

写作时依次辨认：

1. 模型描述的是给定特征后的条件均值，还是响应变量的完整条件分布？“线性”究竟指参数还是原始变量？
2. 用什么依据支持均值形式与遗漏因素处理？含截距模型残差均值接近零是拟合性质，不能据此证明误差外生。
3. 样本是否有重复个体、时间顺序或群组依赖？不相关比独立弱，不要无依据加强前提。
4. 同方差与正态性是否服务于实际使用的区间/检验？稳健标准误也有适用条件，不能修复错误的均值结构或内生性。

二元 Logistic 回归常以二项/Bernoulli 响应结构及连接函数建模，不应套上“响应变量和误差均正态”的线性回归模板。[Penn State：Binary Logistic Regression](https://online.stat.psu.edu/stat504/Lesson06)

适合正文的条件式改写：

> 在选定特征范围内，采用线性形式近似目标量的条件均值，并以条件均值为零的误差项表示未解释的波动；误差的相关结构及方差特征在残差诊断中进一步检查。

该句只适用于实际采用这一模型且有初步结构依据的情况；无法支持条件均值零时，应作为待核对前提，不能由拟合结果反向“证明”。

## Markov：当前状态要具体，时间齐次另行判断

“无后效性”指给定当前状态后，更早历史不再额外改变下一状态的条件分布。状态必须包含当前任务中相关的信息；只写“系统满足 Markov 性”没有解释状态如何承载历史。[MIT：Markov Property](https://ocw.mit.edu/courses/res-6-012-introduction-to-probability-spring-2018/f02929e77a4e43c43c97fcd78d114674_hsQnmrHbbms.pdf)

例如沙漠决策的候选状态可能包含位置、剩余资源、日期和已知天气信息；若天气有持续性，仅记录位置通常不足。日期可以作为状态，也可显式使用时变转移。Markov 性不自动意味着转移概率恒定，也不意味着各时刻相互独立。

可检查增加滞后/持续天数信息是否显著改变预测或策略；无法验证时说明近似范围。使用动态规划还须核对决策信息、资源约束及实际递推结构，不能只靠“动态”二字选定方法。

## 博弈：理性不自动推出非合作、风险中性或完全信息

“理性”要落实到玩家在可获得的信息和行动约束下优化何种效用。最大化期望金钱收益是具体的偏好设定，不是理性的唯一含义；不知道未来天气也不等于行为不理性。

参与者是否合作取决于任务的规则、可达成的协议及建模对象；不能由“理性人”三个字推出不合作。游戏失败如何计分应按题设执行；不能擅自把硬性生存约束换成罚分，也不必将“生命无价”等伦理陈述列成通用数学假设。

## 分布：先说随机变量是什么

| 候选设定 | 必须说清楚的对象和条件 | 常见错误与替代 |
|---|---|---|
| Poisson 计数 | 给定时间长度内的到达/故障次数及暴露时长；强度与工况 | 某时刻排队人数还受服务过程影响，不自动服从 Poisson；过度离散可考虑异质强度或其他计数模型 |
| 齐次 Poisson 到达过程 | 恒定强度、独立增量等过程条件 | 固定边际概率不能证明独立；定时集中到达或高峰期需重新建模 |
| 指数间隔/寿命 | 正值间隔或寿命；指数寿命意味着恒定风险率 | 个体老化、维修或分群可能破坏条件；比较分段风险率、Weibull 等适当候选 |
| 正态产品参数 | 同工况/批次内的具体测量量及尺度；独立性单独说明 | 外观近似钟形不证明批间一致；尾部判废时不能只看中心拟合 |
| Logistic 人口增长 | 封闭或净迁移可近似忽略的范围、增长限制与参数有效期 | Logistic 增长规律不是 Logistic 回归；增长瓶颈和承载量变化不能靠名称确定 |
| 常死亡率/常费用 | 单位、适用群体、时间尺度和外部条件 | 未观测到变化不等于永远不变，可先用分段或情景设定 |

对齐次 Poisson 过程，固定区间的到达数与相邻到达时间分别具有相应的 Poisson、独立同分布指数结构；二者不能与等待服务时间或任意队列长度混用。[MIT：Poisson Processes](https://ocw.mit.edu/courses/6-262-discrete-stochastic-processes-spring-2011/3a19ce0e02d0008877351bfa24f3716a_MIT6_262S11_chap02.pdf) 指数分布的恒定风险率性质见 [NIST：Exponential Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3667.htm)。Poisson 计数的均值方差关系可作为诊断线索，但满足该关系本身并不能证明分布形式。[NIST：Poisson Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366j.htm)

## 核心因素不能按领域惯例删除

传染病模型里忽略年龄/性别差异，只能是与目标、可用分层数据和时间尺度相符的聚合近似，不能默认适用于研究群体差异的问题。交通题若研究行人过街冲突，就不能假设没有行人；人口题若研究流动人口，就不能删去迁移。

这些是从任务结构推出的建模判断，不是特定现实群体的经验结论。选用后仍需按当前题目检查依据。
