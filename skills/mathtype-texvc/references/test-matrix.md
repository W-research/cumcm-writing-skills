# 兼容性与版本测试

[版本使用与测试记录](native-tests.json) 统一登记使用经验和逐项测试；[手工清单](manual-tests.md) 给出测试步骤和可复制公式。`author_usage` 记录作者长期使用的版本组合，不要求截图；`pass` 记录具体用例的验证结果，保留版本和证据要求。

已登记的作者使用组合：**Word 2016（16.0.20527.20088）/ MathType 7.8.2.441**。常规指导可据此写明作者使用经验，具体命令或入口的逐项通过状态仍看对应记录。

| 证据层 | 可以说明什么 | 不能替代什么 |
|---|---|---|
| Wiris桌面文档 | Toggle TeX的输入形式、命令与布局机制 | 当前机器的转换结果 |
| 固定版本Texvc语法 | 参考语法接受的结构 | 特定MathType嵌入版本的兼容性 |
| author_usage | 作者在所填Word/MathType版本下长期使用 | 每一种语法、入口或场景都已逐项验证 |
| 已填写版本和证据的pass记录 | 指定Word/MathType/入口的实测结果 | 其他版本或其他入口 |
| fail或not_run记录 | 已知失败或验证缺口 | 擅自推断普遍不支持 |

author_usage只要求Word和MathType实际版本；ID、备注可用于定位经验范围。逐项测试中align与aligned分开，Toggle TeX与Convert Equations分开；pass仍要求Word和MathType版本、操作系统、日期、入口及可取得的证据文件。

当已有充分实测记录时，可在使用指导中写“在该版本和入口上实测”；没有记录时仍提供有依据的操作建议，并说明适用范围。单个字母的数学标记和转换器能否自动检测它也是两件事。
