# 信贷、评价与优化的论证示例

目录：2020 C 三问方案示例；评价模型取舍；非凸优化纠错；动态规划条件。

## 1. 2020 C：三问分析的方案稿

依据 [官网2020 C题及附件](https://www.mcm.edu.cn/html_cn/node/10405905647c52abfd6377c0311632b5.html)，已读取完整题面、工作表结构和附件1全部企业基本信息；哈希与范围见 [来源清单](official-2020-c-source.json)。以下为基于实际数据条件的原创方案稿，没有训练风险模型或求解信贷配置。

### 问题一：风险量化与信贷配置

问题一同时包含企业风险量化和有限资金下的信贷配置，难点在于将信誉与票据信息转化为对贷款决策有意义的风险表达，并考虑利率变化与客户流失之间的联系。输入为有信贷记录企业的数据及利率与流失率统计信息，输出为企业风险量化结果及是否放贷、额度和利率安排。附件1基本表确有“是否违约”字段，123家中标签“是/否”为27/96；这支持讨论监督风险建模，但标签的时间定义和决策时点可用性仍须确认。可用共同交易特征建立可解释模型并与规则评分比较，验证按企业划分；多张发票不是多个独立企业样本。总体违约频率、风险评分和逐企业概率分别解释。

在风险含义明确后，将信贷策略写成预算约束下的配置问题。与仅按风险排序后分配资金的基线相比，联合配置能够表达利率、流失和收益之间的相互影响；但具体属于线性、整数或非线性模型，需要由变量和收益表达确定。求解后拟复算单笔额度、利率与总额约束，并按标签和样本条件选择留出校核或排序稳定性检查。题目未唯一规定收益与风险的权衡口径，其操作化目标需在建模部分明确。

### 问题二：信息变化下的风险估计

问题二把对象换成无信贷记录企业，本质上是在信息条件变化下进行风险估计与资金配置。附件2基本表只含代号、名称，没有附件1的评级与违约字段。输入为公共交易特征、适用风险表达及1亿元预算，输出为风险量化结果和信贷策略。关键困难是缺失的历史信贷信息可能恰好是前一模型的重要特征，因此不能把问题一模型原样套用并宣称有效。

拟以两类企业的公共特征构建可迁移的风险表达，并在有记录样本中检查去除专属信息后的表现；相较于完全重新构造无监督评分，这条路线可保留历史标签信息，但前提是标签和公共特征足以支持迁移。若样本差异使该前提不成立，应改用有明确解释的评价方案，并说明缺少目标样本真实标签的验证限制。风险估计之后再按本问预算求解信贷配置，检查适用范围与约束满足情况；本问复用的是合理的特征或机制，不是第一批企业的贷款结果。

### 问题三：冲击下的情景调整

问题三在同一批无信贷记录企业上引入突发因素，是情景变化下的风险评估与策略调整问题。输入为问题二的风险估计和基准策略，以及有来源支持的情景参数；输出为年度总额 1 亿元条件下的调整方案。主要困难是冲击强度和作用方向可能因企业或行业不同而改变，不能简单把所有企业风险统一乘同一个比例。

当缺少可信情景概率时，拟以明确的冲击情景进行比较，并根据题目目标考虑情景优化；相较于直接按主观概率建立期望收益模型，这可以避免把不可靠概率掩盖在单一结果中。若需要对不利情景提供保护，则进一步论证鲁棒优化及其保守程度。求解时保留预算和单笔条件，通过情景敏感性与基准策略对照检查调整是否由冲击机制驱动；这些检查提供条件化证据，不能声称预测了真实突发事件。

### 题面与数据处理检查

负数发票可反映退货退款，与作废状态不同；处理应保留其经济含义。附件1/2进销项表顺序不同，要按名称和字段读取。对选中放贷者施加10–100万元和4%–15%条件，保留不放贷选项及D级原则限制。第一问年度总额固定但未给1亿元，不能把后问预算前移。

### 可迁移规则

- 每问都写清数学任务、输入输出、难点、求解和检验；候选取舍只在存在实质选择时展开。
- 信息缺口本身可以成为建模分析的重要内容，不能拿虚构的 EDA 结果填补。
- 比较可在理论层面成立，不要求把所有候选都跑一遍。
- “风险评分—风险概率—预期损失”含义不同，接口必须说明。

## 2. 综合评价：从“指标多”改成真正的理由

U1 的好例强调解释选择，比纯算法流水账更有价值；但“指标多且有模糊性，所以模糊评价 + 熵权”还不充分。

原创教学情境：评价资料同时含可测量指标与专家给出的语言等级，等级边界确有交叠，任务需要形成等级评价。

可用写法：“本问需要将定量指标和语言等级信息统一为方案评价。其难点是部分等级的边界并非截然分开，直接把专家判断编码为单一分值可能丢失这种信息，因此拟采用具有明确隶属度定义的模糊综合评价，并与统一量纲后的加权评分比较。权重根据实际可得的客观数据和决策偏好分别确定，再通过权重扰动及等级一致性检查评价结论的稳定性。”

**为何更好：**理由落到信息形式与输出语义；替代方案合理；检验针对权重及等级依赖。

**边界：**如果全部指标是明确可测的量且只需排序，不能照搬“模糊性”；熵权反映样本离散差异，不能自动代表指标的重要性，也没有消除指标选择和预处理中的判断。

## 3. 非凸目标：修正原“好例”的数学冲突

有问题的逻辑：连续决策变量、线性约束 → 线性规划；目标非凸 → 遗传算法验证全局最优。

原创修订：“本问在给定约束下选择连续决策变量，但目标包含非凸项，因此不能直接归类为线性规划。拟根据目标的可微性与规模比较多初值非线性求解和启发式搜索，并以可行性复算、简单可行基线以及可获得的界评价解的质量；只有得到适用的全局证据时才报告全局最优。”

原示例的“对比并解释”可以学习，数学结论必须修正；技术依据见 [来源 M1、M2](sources.md)。

## 4. 动态决策：不要只看到时间维度

弱：“第三问有时间维度，因此采用动态规划，状态由上一问决策变量自然得到。”

原创修订：“第三问需连续决定各期动作，当前选择会影响后续可用资源，因此拟用能概括剩余资源及必要历史信息的状态描述过程。若该状态足以确定可行行动和转移规律，可建立动态规划；相较于逐期独立优化，它能够表达跨期影响，但需要检查状态规模与计算代价。若状态过大，则比较滚动优化，并以小规模可解情形和跨期约束复核检查策略。”

状态如何定义需基于题目机制；“前问决策变量自然变成状态”不是通用规则。
