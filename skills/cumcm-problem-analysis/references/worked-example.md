# 可复核回写案例：固定水量关系与有限候选

## 完整输入与已有实现

- **F1**：容器初始水量 5 m³，三个连续的 1 h 时段，各段内进、出流量分别恒定，基准模型没有其他水量项。
- **F2**：各段累计进水量 `[10, 8, 12]` m³，出水量 `[9, 11, 10]` m³。
- **F3**：问题一固定使用“期末水量 = 上一期水量 + 进水量 − 出水量”，给出三个期末值和全期最大值。
- **F4**：问题二候选容量 `[5, 6, 8]` m³，费用 `[1000, 1200, 1600]` 元，要求全期不溢流且在给定候选中费用最低。
- **F5**：问题三把每段进水乘以 1.2，其他条件不变，检查原方案与全部原候选的可行性，给出最低容量需求。

已有实现如下。它是合成案例的实际计算定义，不是从未知原论文补出的代码：

```python
from decimal import Decimal as D

def levels(inflow):
    s = D("5")
    out = []
    for q_in, q_out in zip(inflow, map(D, ["9", "11", "10"])):
        s += q_in - q_out
        out.append(s)
    return out

base = levels(list(map(D, ["10", "8", "12"])))
peak = max([D("5")] + base)
options = [(D("5"), 1000), (D("6"), 1200), (D("8"), 1600)]
feasible = [(capacity, cost) for capacity, cost in options if capacity >= peak]
chosen = min(feasible, key=lambda item: item[1])
shock = levels([D(x) * D("1.2") for x in ["10", "8", "12"]])
shock_peak = max([D("5")] + shock)
```

该代码只针对上述长度一致的完整输入演示计算，不是通用数据处理工具。

## 结果记录与可复算检查

- **E1**：`base = [6, 3, 5]` m³，`peak = 6` m³。三个区间的水量均非负。段内恒流使储量在各段线性变化，初值和端点足以检查全期极值。
- **E2**：容量 5 不足，6 和 8 可行；`chosen = (6, 1200)`。这是给定三候选集合中的最便宜可行解，不代表未知连续价格函数的最优解。
- **E3**：`shock = [8, 6.6, 11]` m³，`shock_peak = 11` m³，所有原候选均不足。题目只给一种扰动情景，没有概率或新容量报价。
